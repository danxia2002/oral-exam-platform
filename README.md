# AI-Powered Oral Examination Platform

## Overview
This project presents an AI-powered oral examination platform that simulates traditional oral exams using large language models and voice interaction technologies. The system supports automated question delivery, response evaluation, and real-time feedback generation.

## Features
- AI-generated oral exam questions  
- Automated grading using LLM-based evaluation  
- Real-time feedback for student responses  
- Performance analytics (average score, standard deviation)  
- Simulated student evaluation dataset  

## Technologies Used
- Python (FastAPI)
- OpenAI API (GPT-4o-mini)
- ElevenLabs (Text-to-Speech)
- HTML/CSS (Frontend)
- Excel (Data analysis)

## How to Run
1. Clone the repository  
2. Install dependencies  
3. Add API keys (OpenAI, ElevenLabs)  
4. Run the FastAPI server  
5. Access the application via localhost  

## Project Purpose
This project was developed as part of an Applied Project to explore the feasibility of AI-driven oral assessments and evaluate their effectiveness in terms of scalability, consistency, and reliability.

## Dataset
The dataset used in this project is simulated and includes high-, medium-, low-, and mixed-quality responses for evaluation purposes.
